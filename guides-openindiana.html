Understand the illumos family

OpenIndiana is an illumos-based operating system. illumos is a family/ecosystem with several distributions; package tools and release details vary. This is not Linux and not identical to Oracle Solaris. Check the exact distribution and release before following instructions.

Packages and updates

OpenIndiana uses the Image Packaging System (IPS). Use the official repositories and release notes. Avoid mixing package sources from unrelated illumos distributions or Solaris releases.

Storage and services

ZFS is a major part of the ecosystem. Understand pools, datasets, snapshots, and backups before changing storage. Snapshots do not replace independent backups. Learn the service management framework and network configuration from the distribution's documentation.

Hardware and troubleshooting

Hardware support can be narrower than mainstream desktop operating systems. Check supported hardware before installation and retain installation media. Record the exact release, system architecture, device model, and log messages when asking for help.

Troubleshooting and further help

Record the exact OS release, hardware model, error text, and changes made. Do not share passwords, recovery codes, or private keys.
