A different desktop operating system

Haiku is an open-source operating system inspired by BeOS. It has its own desktop, filesystem conventions, package ecosystem, and application compatibility. Linux desktop instructions do not apply directly.

Hardware compatibility

Check the current hardware compatibility information before installing, especially for Wi-Fi, graphics, audio, and newer laptops. Test using supported live media where available and back up existing files before changing partitions.

Applications and packages

Use HaikuDepot and official package repositories. Check whether an application is built for the current Haiku architecture and release. Do not assume Linux binaries or drivers will work.

Updates and help

Read release notes before updating and keep a backup of important data. When reporting a bug, include the Haiku build, hardware model, steps to reproduce, and relevant logs.

Troubleshooting and further help

Record the exact OS release, hardware model, error text, and changes made. Do not share passwords, recovery codes, or private keys.
