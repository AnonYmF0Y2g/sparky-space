Choose the right Fedora edition

Fedora Workstation, Fedora Server, and Fedora Atomic/bootc-based variants have different workflows. Identify the edition and release before applying advice. Fedora releases have a shorter lifecycle than many LTS distributions, so plan upgrades regularly.

Packages and updates

Fedora uses DNF for traditional package management and may use Flatpak for desktop apps. Use Fedora's official repositories and trusted Flatpak remotes. Review transaction summaries before accepting removals or package replacements.

SELinux is a security feature

SELinux enforces access-control policy. Do not disable it as a generic troubleshooting step. If an application is blocked, inspect the relevant denial and consult Fedora documentation to understand the policy. Avoid copying broad policy exceptions from unknown sources.

Graphics, Wi-Fi, and upgrades

Record the hardware model, kernel version, and exact error. Some proprietary driver workflows are community-maintained and may have different support guarantees. Back up before release upgrades and read Fedora's official upgrade guidance.

Troubleshooting and further help

Before asking for help, include the exact device model, operating-system version, error message, when the problem began, recent changes, and safe checks already completed. Do not share passwords, recovery codes, private keys, or personal documents.
