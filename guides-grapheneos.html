Check supported hardware

GrapheneOS supports a specific list of Google Pixel devices. Check the current official device list before buying hardware or attempting installation. Compatibility changes over time; a similar model name is not enough.

Installation and updates

Use only the official installation instructions and verified web installer. Read prerequisites, backup requirements, bootloader state, and device-specific steps. Installation and bootloader changes can erase data. Keep the OS updated through its supported updater.

App compatibility and permissions

Understand the optional Google Play compatibility layer and app sandboxing. Review network, sensor, storage, and location permissions. Some banking, payment, streaming, or work apps may have compatibility limits because they expect particular device integrity signals.
