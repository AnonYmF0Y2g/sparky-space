Identify your Mac and macOS release

Choose Apple menu → About This Mac to record the model, chip or processor, memory, serial-independent model identifier if needed, and macOS version. Check Apple's compatibility list before expecting a particular macOS release to install. Intel Macs and Apple silicon Macs can have different recovery and hardware procedures.

Updates and application sources

Use System Settings → General → Software Update for supported macOS updates. Prefer the Mac App Store or the developer's verified website for applications. Review app permissions under Privacy & Security, especially camera, microphone, location, files, and accessibility access. Remove permissions for apps that no longer need them.

Storage, memory, and battery

Use System Settings → General → Storage to inspect large files and recommendations. Activity Monitor helps distinguish CPU pressure, memory pressure, energy use, and disk activity. Check Battery settings for battery condition and usage patterns. Heat, poor ventilation, and constant high workloads can affect performance and battery longevity.

Backups and recovery

Set up Time Machine with a suitable external backup destination and periodically verify that backups complete. A backup drive should not be the only copy of irreplaceable files. Before macOS reinstallations, disk changes, or service, ensure your backup is current and that you know the Apple Account recovery process.

Troubleshooting

Mac runs slowly: check Activity Monitor and free storage first. App will not open: update it, check compatibility and privacy prompts, then consult its developer. Wi-Fi trouble: compare another device and network before changing router settings. Startup trouble: use Apple's model-specific startup and recovery instructions rather than random key combinations from unrelated Mac models.

Troubleshooting and further help

Before asking for help, include the exact device model, operating-system version, error message, when the problem began, recent changes, and safe checks already completed. Do not share passwords, recovery codes, private keys, or personal documents.
