Before you run anything

No tests run automatically. The local checks below display results in this page only. Sparky's Space does not send test results to its database or save them in your account.

Important: the public-IP check contacts ipify, and the WebRTC check contacts Google's public STUN server. Those providers can see the network address used for those requests. A third-party DNS test also sees its own test traffic. Their privacy and retention practices are separate from Sparky's Space.

DNS leak testing

A reliable DNS leak test needs a test service to receive DNS queries and report which resolvers handled them. This website does not operate that infrastructure, so it will not pretend to measure DNS leaks locally.

After reading the provider's privacy information, you can choose to open a third-party DNS test. That provider may see your public IP address and the resolver addresses involved in the test. Results are shown on its website, not stored by Sparky's Space.

External service: DNSLeakTest.com. This is optional and is not operated by Sparky's Space.

What these checks mean

  • Public IP: shows the address seen by the IP-check provider. A VPN may change the address websites see, but this alone does not prove that all traffic uses the VPN.
  • WebRTC: checks whether the browser gathers host or server-reflexive ICE candidates. Browser privacy settings and mDNS can change what is visible; an inconclusive result is possible.
  • Secure context: checks whether this page is loaded over HTTPS.
  • Privacy signals: reads browser-provided Global Privacy Control and Do Not Track signals. These are preferences, not technical blocking guarantees.
  • DNS: must be checked by a DNS test provider or by examining device/router configuration. A web page cannot reliably infer all system DNS behavior from a simple browser request.

No result proves that a person is anonymous or untraceable. These are limited snapshots, not a penetration test, malware scan, or audit of the whole device.
