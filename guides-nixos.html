NixOS is configuration-driven

Much of the system is described in declarative configuration files rather than edited through traditional one-off changes. The main system configuration is commonly stored in /etc/nixos/. Back up configuration before changing it and understand whether a setting belongs in the system configuration, a user environment, or a development shell.

Build and switch carefully

Read the NixOS manual for the correct command and workflow for your release. Review evaluation and build errors before switching. System generations can provide rollback options, but they are not a replacement for backups of personal data or secrets.

Packages and services

Nix package expressions and options can differ from conventional Linux package manager instructions. Search the official option reference for the exact option and release. Avoid copying configuration snippets without understanding their effect, especially for networking, boot, storage, and firewall settings.

Troubleshooting and further help

Before asking for help, include the exact device model, operating-system version, error message, when the problem began, recent changes, and safe checks already completed. Do not share passwords, recovery codes, private keys, or personal documents.
