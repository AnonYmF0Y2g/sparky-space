Desktop and Server are different editions

Ubuntu Desktop includes a graphical environment; Ubuntu Server is designed for managed services and may not include a desktop. Identify the release and whether it is an LTS or interim release. Check the official lifecycle page so you know how long security maintenance is available.

Software and updates

Use Software Updater or the supported APT workflow for system packages. Ubuntu also uses Snap packages for some applications. Prefer official Ubuntu repositories and verified vendor instructions. Avoid mixing repositories intended for another Ubuntu release or a different Debian-based distribution.

Drivers and hardware

Use Software & Updates → Additional Drivers where available, or consult Ubuntu's hardware documentation. For Wi-Fi, graphics, printers, and suspend issues, record the exact device model and kernel version. Firmware support can vary by hardware vendor.

Maintenance and recovery

Keep backups before release upgrades. Check free storage and read the release notes before moving between supported versions. For boot or package problems, capture the full error and avoid force-removing core packages. Ubuntu recovery options depend on whether the system uses UEFI, encryption, and separate partitions.

Troubleshooting and further help

Before asking for help, include the exact device model, operating-system version, error message, when the problem began, recent changes, and safe checks already completed. Do not share passwords, recovery codes, private keys, or personal documents.
