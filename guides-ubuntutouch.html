Device support is specific

Ubuntu Touch support depends on exact phone model, variant, and port status. Check the official supported-device list before buying or installing. A device that can boot a community port may not have fully working camera, calls, mobile data, or suspend.

Installation and backups

Use UBports' official installer and device-specific documentation. Bootloader changes and OS installation can erase data. Back up photos, files, contacts, and authenticator access and confirm that the device can be restored to its original software if needed.

Apps and updates

Ubuntu Touch has a different app ecosystem from Android and iOS. Check whether essential applications and services are available before switching. Install updates through the supported updater and read release notes.

Troubleshooting

For camera, calls, Wi-Fi, or mobile-data faults, check the device page and known issues. Include the device codename, channel, OS build, and symptoms when asking the community for help.
