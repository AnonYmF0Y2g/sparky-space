Linux is a family, not one single operating system

Distributions combine the Linux kernel with different package managers, release models, desktop environments, security defaults, and support communities. Instructions for Ubuntu are not automatically correct for Arch, Fedora, Kali, or Alpine. Always identify the exact distribution and version before following commands.

Identify your distribution

Look in Settings → About or consult the distribution's release information. On many systems, the file /etc/os-release contains distribution identification. Record the version, desktop environment, CPU architecture, and whether the system is a live session, installed system, container, or virtual machine.

Before changing a Linux system

Back up important files and configuration. Read release notes before a major upgrade. Avoid mixing repositories from different distributions or releases. Do not run commands copied from a forum without understanding what they change. Keep a recovery method available before altering bootloaders, filesystems, encryption, or network configuration.

Troubleshooting and further help

Before asking for help, include the exact device model, operating-system version, error message, when the problem began, recent changes, and safe checks already completed. Do not share passwords, recovery codes, private keys, or personal documents.
