Check the Chromebook model and update support

Open Settings → About ChromeOS to view the version and update status. Check the device's Auto Update Expiration (AUE) date using Google's official list. A Chromebook may continue to start after automatic updates end, but it will no longer receive the same ongoing platform security updates.

Keep ChromeOS healthy

Install updates through Settings → About ChromeOS. Review extensions at chrome://extensions and remove anything you do not recognize or need. Extensions can read or modify browsing data depending on their permissions. Check storage before downloading large files and use the built-in diagnostics for battery, memory, and connectivity where available.

Linux development environment

Some Chromebooks offer the Linux development environment (Crostini). Availability depends on the model, administrator settings, and ChromeOS version. Use the built-in settings to enable it, keep packages updated using the distribution's package manager, and back up Linux files before removing or resetting the environment. Do not enable developer mode simply because a random guide recommends it; it can reduce security and wipe local data.

Powerwash and recovery

Powerwash resets local user data. Confirm cloud sync and back up local Downloads and Linux files first. ChromeOS recovery is a separate process that reinstalls the operating system and may require recovery media. Follow Google's exact instructions for your device.

Common problems

Slow tabs: close unused tabs and check extensions. Wi-Fi: verify whether other devices connect and check captive-portal sign-in. Updates fail: check storage, network stability, and AUE status. Linux apps fail: check whether Linux is enabled and whether the app supports the Chromebook's CPU architecture.

Troubleshooting and further help

Before asking for help, include the exact device model, operating-system version, error message, when the problem began, recent changes, and safe checks already completed. Do not share passwords, recovery codes, private keys, or personal documents.
