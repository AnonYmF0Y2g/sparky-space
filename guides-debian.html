Understand Debian releases

Debian Stable prioritizes predictable releases and long-term maintenance. Testing and Unstable have different change rates and are not interchangeable with Stable. Identify the release codename before following instructions. Check Debian's security and LTS pages to understand the support window for the release you use.

APT and repositories

Use the package sources appropriate for the release and architecture. Keep repository entries consistent; do not mix Ubuntu PPAs or unrelated distribution repositories into Debian. Read package manager prompts before accepting removals or major dependency changes. Save the full output if an update fails.

Firmware and hardware

Some Wi-Fi, graphics, and other devices require non-free firmware packages depending on the Debian release and installation media. Use Debian's official installation and firmware documentation. Identify the hardware model before buying an adapter or assuming a driver is missing.

Upgrades and troubleshooting

Back up user data and important configuration before a release upgrade. Read the release notes, ensure adequate disk space, and use a stable power and network connection. For a failed boot, record the last visible message and whether the issue began after a kernel or firmware update.

Troubleshooting and further help

Before asking for help, include the exact device model, operating-system version, error message, when the problem began, recent changes, and safe checks already completed. Do not share passwords, recovery codes, private keys, or personal documents.
