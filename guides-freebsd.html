FreeBSD is not a Linux distribution

FreeBSD is a separate Unix-like operating system with its own kernel, base system, documentation, release process, and package tools. Linux driver and administration instructions do not automatically apply. Check the exact FreeBSD release and hardware support list.

Packages and ports

Use the supported pkg package manager for binary packages. The Ports Collection provides build recipes and additional customization, but compiling software can require time, storage, and dependency knowledge. Follow the handbook for repository and package configuration.

Storage, networking, and services

FreeBSD supports ZFS and UFS; their maintenance and recovery requirements differ. Understand your filesystem and backup plan before changing disks or boot configuration. Services are commonly configured through rc.conf and managed using FreeBSD's service tools, not systemd.

Jails and security

Jails provide operating-system-level isolation. Learn their networking, storage, and privilege model from the official handbook before deploying services. Keep the base system and packages updated and expose only services that are necessary.

Troubleshooting and further help

Before asking for help, include the exact device model, operating-system version, error message, when the problem began, recent changes, and safe checks already completed. Do not share passwords, recovery codes, private keys, or personal documents.
