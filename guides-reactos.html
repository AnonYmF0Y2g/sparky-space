Understand the project's status

ReactOS is an open-source project aiming for compatibility with Windows applications and drivers. It is not a drop-in replacement for a supported Windows installation and should be treated as experimental. Do not rely on it for sensitive data, critical work, or production systems.

Test safely

Evaluate ReactOS in a virtual machine or on non-critical spare hardware. Use snapshots and disposable test data. Check the current hardware and software compatibility lists before expecting a particular application or driver to work.

Updates and compatibility

Follow official project releases and documentation. Windows drivers and applications may behave differently depending on version and implementation. Avoid installing unknown drivers or using personal credentials in an experimental environment.

Report problems

Include the ReactOS build, virtual or physical hardware details, application version, and repeatable steps. Keep tests isolated and back up the host system separately.

Troubleshooting and further help

Record the exact OS release, hardware model, error text, and changes made. Do not share passwords, recovery codes, or private keys.
