Portable BSD system

NetBSD is known for supporting a wide range of hardware architectures. That breadth means hardware support varies substantially by machine and release. Check the official supported platforms and installation notes for your exact system.

Packages and pkgsrc

NetBSD uses pkgsrc for third-party software. Binary packages and source builds have different requirements. Use documentation matching the release and architecture; do not apply FreeBSD ports or Linux package instructions directly.

System configuration

Learn the NetBSD rc system, network configuration, filesystems, and boot process from the handbook. Back up configuration before changing storage, bootloader, or network settings.

Troubleshooting

Check the release, architecture, kernel messages, and device driver support. When reporting a problem, include the machine model, exact hardware component, and relevant log output with personal information removed.
