Arch is a rolling-release distribution

Arch receives ongoing package updates rather than periodic fixed-version releases. Partial upgrades are unsupported: do not update one package while leaving the rest of the system at an incompatible state. Read news notices before a full system upgrade, especially when configuration or package transitions are announced.

pacman and package sources

Use pacman for official repository packages and read its transaction summary. The Arch User Repository (AUR) contains user-submitted build scripts; review the PKGBUILD and understand what will be downloaded and built before using it. An AUR package is not automatically reviewed or supported by Arch Linux.

Maintain a recovery route

Keep installation media available and maintain backups of important files and system configuration. Understand your bootloader, filesystem, encryption, and partition layout. Do not remove old kernels or boot components until you know a working recovery path exists.

Common problems

Upgrade conflict: read Arch news and the complete pacman output. Boot failure: identify the bootloader and filesystem before changing configuration. Missing network: check the network manager and firmware for the exact adapter. Desktop failure: use a TTY only if you understand the login and recovery process, and keep notes of changes.

Troubleshooting and further help

Before asking for help, include the exact device model, operating-system version, error message, when the problem began, recent changes, and safe checks already completed. Do not share passwords, recovery codes, private keys, or personal documents.
